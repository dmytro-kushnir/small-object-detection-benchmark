# EXP-001 — Train-only removal of small boxes (COCO128)

**Status:** Concluded (pilot with clear negative takeaway).

**Question:** If we drop small training instances, does validation **mAP_small** improve?

**What we did:** Train split filtered (`filter.apply_to: train`, `min_area_px: 1024`); **val GT unchanged** vs EXP-000 for fair mAP comparison.

**Conclusion (recorded):** **mAP_small unchanged**; overall mAP@.50 and mAP@[.5:.95] **degraded** vs EXP-000 on the logged run. Treat as evidence that this filter is **not** a small-object win on this schedule; longer runs needed for stronger claims.

**Paper role:** Background / negative data-prep result (Table S2: “not in Tables 1–4”).

**Key artifacts:** `experiments/results/test_run_exp001_metrics.json`, `experiments/results/exp001_vs_baseline.json`.
