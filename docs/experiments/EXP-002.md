# EXP-002 — Higher resolution training (1280 vs 320 smoke)

**Status:** Concluded (controlled “single big change” vs EXP-000).

**Question:** Does raising train/infer `imgsz` to **1280** improve small-object metrics on the same val GT as EXP-000?

**What we did:** Same prepared data as EXP-000; only `imgsz` differs (1280). 1 epoch, same model family as smoke.

**Conclusion (recorded):** **mAP_small** and **mAP_medium** rise strongly vs 320, but **overall mAP@[.5:.95]** and **mAP_large** fall; matched precision drops while recall rises—consistent with more detections but messier localization at one epoch. Inference slower (lower FPS).

**Paper role:** Background illustrating that resolution helps **area buckets** but is not a free lunch at minimal training (Table S2: informs `imgsz` discussion, not main trophallaxis tables).
